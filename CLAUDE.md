# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Состояние проекта

Репозиторий пока пустой (нет кода, сборки, тестов). Это учебный проект. Когда появятся код и инструменты, добавьте сюда команды сборки/запуска/тестов и описание архитектуры (можно перезапустить `/init`).

## Предпочтения пользователя

- Общение на русском языке.
- Проект учебный: объяснять простыми словами, что и зачем делается.
- Пользователь хочет научиться работать со слэш-командами Claude Code (`/model`, `/init`, `/resume`, `/config` и т.д.). Тренировать его: когда уместно, напоминать про подходящую слэш-команду, коротко объяснять, что она делает, и предлагать попробовать её самому, а не выполнять действие за него.
