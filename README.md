# Crimson Vigil — Багровое бдение

Готический roguelite-шутер от первого лица. Охотник Гидеон Вейл с револьвером «Реквием» и арбалетом
«Покаяние» проходит одну ночь: деревня Холлоумир → Терновый лес → собор Святого Ашена → замок Морвейн.

## Как запустить
1. Дважды щёлкнуть `start.bat`. Откроется браузер на `http://localhost:8080`.
   Или вручную: `python tools/serve.py` и открыть адрес в Chrome/Edge.
2. Нажать «Начать охоту». Мышь захватывается щелчком, Esc ставит паузу.

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ / ПКМ | прицел / выстрел / прицеливание |
| R | перезарядка (револьвер заряжается по патрону, выстрел прерывает перезарядку) |
| 1 / 2 / колесо | револьвер / арбалет |
| Q | рывок-уклонение (неуязвимость на мгновение) |
| Shift / Space | бег / прыжок (так можно перепрыгнуть ударную волну) |
| G / колёсико | фляга святой воды (3 на зону) |
| E | алтари, торговец, источник, гробы |

## Что внутри
- 4 биома с процедурными локациями, 5 видов врагов и элитные аффиксы, 4 босса.
- Награды 1-из-3: 24 реликвии и 8 улучшений оружия. Торговец, кровавый алтарь, модификаторы зон.
- Мета-прогрессия: кровавые осколки → Святилище Ордена.
- Всё процедурное: текстуры, модели, звук (WebAudio). Внешних ассетов нет.

## Для разработки
- Документы: `GAME_DESIGN.md`, `DECISIONS.md`, `PROGRESS.md`.
- Скриншот без браузера: `powershell -File tools/shot.ps1 -Query "scenario=overview&biome=village" -Name test`.
- Автопрогон забега ботом: `-Query "scenario=flow&god&steps=20000"`.
