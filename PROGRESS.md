# Прогресс и дорожная карта

## Как запустить
```powershell
python tools/serve.py          # сервер на http://localhost:8080
# открыть в Chrome: http://localhost:8080
```
Проверка кадра без браузера:
```powershell
powershell -File tools/shot.ps1 -Query "scenario=overview" -Name overview
# → screenshots/overview.png и screenshots/overview.log
```

## Цикл разработки
реализовать → запустить сценарий → посмотреть скриншот и лог → отладить → улучшить → коммит

## Журнал
### 2026-10-05
- Окружение: Git 2.55 поставлен через winget, Python 3.14 (через install manager), Chrome есть.
  Node отсутствует, поэтому без бандлера (см. DECISIONS D1).
- Проверено: headless Chrome рендерит WebGL через SwiftShader, console-лог пишется в stderr.
- Нюанс: `--screenshot` не захватывает тяжёлый WebGL-холст. В режиме сценария кадр копируется
  через `toDataURL()` в `<img>`, и уже его снимает Chrome.
- M1: вертикальный срез (револьвер, вампир, HUD, меню, волны). QA-бот `scenario=bot` прогоняет 100 с боя.
- M2: арбалет с кольями, смена оружия, дождь, молнии.
- M4: зоны → награды → врата; 24 реликвии, 8 улучшений оружия, торговец, кровавый алтарь,
  модификаторы зон, мета-прогрессия (осколки + Святилище Ордена). `scenario=flow` проходит забег ботом.
- M5: генераторы биомов: деревня, лес, склеп, двор замка, тронный зал. Параметр `?biome=` для проверки.

- M3/M6: 4 новых вида врагов и 4 босса. Бот в режиме god прошёл всю ночь от деревни до победы над Сувереном.
- M8: настройки (мышь, FOV, звук, качество), динамическое разрешение, пауза с меню, экран загрузки,
  титульная карточка, обучающие подсказки, руки охотника, start.bat.

### Сессия 2 — атмосфера и окружение
- Баланс: проверка ботом со 100 HP (деревня проходима, Мясник смягчён, Матерь Стаи крепче).
- Лунные лучи: радиальный проход к экранной позиции луны; источник — только небо у луны.
- Трава и подлесок: тысячи пучков одним InstancedMesh, ветер в вершинном шейдере.
- Живая атмосфера (`world/ambience.js`): пепел и искры над деревней, светлячки и споры в лесу,
  пыль в помещениях, стаи летучих мышей у луны, полосы тумана, лужи, глаза в темноте, дым из труб.
- Звук: процедурная музыка (органный гул, хор ре-минора, боевые барабаны, темп босса),
  звуки биомов (совы, волчий вой, вороны, капель).
- Окружение: вороны (взлетают от выстрелов), горгульи, клетки висельников со скелетами, паутина,
  святые в нишах фасада, высокие витражи, зигзаги молний в небе, перчатка на арбалете.

### Сессия 3 — ночная автономная работа
- Небо: дождь убран (густой туман), кровавая луна, тема «сумеречно-зелёное» (настройка «Небо»),
  готический замок на утёсе в задниках, фонари в лесу, двор замка с центральным шпилем.
- Фляга святой воды (G/колёсико): лужа святого огня, 3 заряда на зону.
- Серия убийств «Кровавая жатва»: множитель золота, вехи.
- Новый враг: вурдалачий волк. Новые реликвии: Освящённая фляга, Мощи мученика, Гнев небесный, Серп жнеца.
- Появление боссов с полосами кино и крупным именем; реликвии и лучшая серия на экране итогов.
- События: запечатанный гроб (сокровище или засада), записки охотников (10 обрывков лора).
- Меню: силуэт Гидеона Вейла, Бестиарий Ордена (10 записей), «Кровавая ночь» после первой победы.
- Третье оружие — двустволка «Литания» (клавиша 3): 9 картечин, переломное заряжание; улучшения «Серебряная дробь», «Чок-сужение».
- Ауры элиты и боссов: искры цвета аффикса — элиту видно издалека.
- Пролог первой ночи на титульной карточке (только в самом первом забеге).
- Гробы и записки ставятся только в достижимые места (проверка прохода от центра арены).
- Регрессия: бот (god) прошёл деревню, лес с боссом и собор без ошибок.
