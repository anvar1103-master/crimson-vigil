# Прогресс и дорожная карта

## Как запустить
```powershell
python tools/serve.py          # сервер на http://localhost:8080
# открыть в Chrome: http://localhost:8080
```
Проверка кадра без браузера:
```powershell
powershell -File tools/shot.ps1 -Query "scenario=overview" -Name overview
# → screenshots/overview.png и screenshots/overview.log
```

## Цикл разработки
реализовать → запустить сценарий → посмотреть скриншот и лог → отладить → улучшить → коммит

## Дорожная карта
- [ ] **M0. Инфраструктура:** git, Three.js, сервер, скриншоты, документы
- [ ] **M1. Вертикальный срез:** игрок, движение, камера, готическая локация (кладбище у собора),
      револьвер, стрельба, вампир, свет, туман, базовый HUD
- [ ] **M2. Ощущения от боя:** арбалет, гильзы, кровь, декали, слоу-мо, дождь и молнии, звук
- [ ] **M3. Бестиарий:** отродья, нетопыри, ведьма, упырь, элитные аффиксы
- [ ] **M4. Структура забега:** зоны, генерация арен, награды 1-из-3, реликвии, золото, переходы
- [ ] **M5. Биомы:** деревня, лес, собор и склепы, замок
- [ ] **M6. Боссы:** Звонарь, Матерь Стаи, Бледный Суверен
- [ ] **M7. Мета-прогрессия:** убежище Ордена, кровавые осколки, разблокировки
- [ ] **M8. Полировка:** меню, звук, оптимизация, настройки графики, баланс
